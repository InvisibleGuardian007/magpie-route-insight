怎么读这张卡

指纹：自述（模型名 / 厂商 / 知识截止 / 自评可信度）+ 系统提示泄漏探针，先落到 13 个家族打分，再把家族摊到网关清单里的具体型号上排名；路由权重 1，自述按可信度打折，自评「不确定」只算 0.25。

HTML 动画：要一份从 <!DOCTYPE> 开始的完整 HTML，里面用 CSS 关键帧画会动的鹈鹕骑车；脚本和外部链接会被洗掉，再放进 iframe 里真跑一遍。提示词可以自己改，留空就用默认那句；产物按一屏等比缩放显示，看不到滚动条。

候选排名只在候选之间归一化，是打分不是统计置信度；库外模型也可能得到相近候选。

检测会花真实积分，跑前先看右上角「预计 N 次请求」。历史只保留最近 6 次的完整结果，点一下能重新打开。
